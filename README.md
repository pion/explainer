### Building

This project is built with [SvelteKit](https://kit.svelte.dev/) and [Vite](https://vitejs.dev/).

Install dependencies:

```sh
npm install
```

Run a local development server:

```sh
npm run dev
```

Build for production:

```sh
npm run build
```

Preview the production build locally:

```sh
npm run preview
```
